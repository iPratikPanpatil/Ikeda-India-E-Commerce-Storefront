# Ikeda India – E-Commerce Storefront

Live site: https://ikedaindia.in/

## Overview
Built and launched an independent e-commerce storefront as the sole developer — 
handling everything from hosting setup to payment integration and catalog structure.

## Tools Used
- WordPress
- WooCommerce
- Razorpay (payment gateway)
- SEO Analytics

## What I Did
- Set up hosting and configured the WordPress + WooCommerce environment from scratch
- Integrated Razorpay for secure payment processing
- Structured the product catalog and category hierarchy
- Added product pages regularly and monitored SEO performance metrics
- Tracked product page visibility and keyword indexing to improve organic search ranking
